MISE A JOUR GITHUB
1. Décompresser le ZIP.
2. Dans le dépôt GitHub, remplacer index.html, app.js, styles.css, sw.js, manifest.webmanifest et programme.png.
3. Ajouter les dossiers icons et exercises en conservant leurs noms.
4. Valider le commit.
5. Attendre 1 à 3 minutes, puis rouvrir l’application.
6. Si l’ancienne version reste affichée : fermer l’application, l’ouvrir dans Safari et actualiser. Au besoin, supprimer puis réajouter l’icône de l’écran d’accueil.

Les données restent locales sur l’iPhone. Utiliser Réglages > Exporter pour créer une sauvegarde.
