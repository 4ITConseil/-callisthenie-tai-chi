INSTALLATION SUR IPHONE
1. Hébergez le contenu de ce dossier sur une adresse HTTPS.
2. Ouvrez cette adresse dans Safari sur l’iPhone.
3. Touchez Partager > Sur l’écran d’accueil > Ajouter.

TEST LOCAL SUR ORDINATEUR
Dans ce dossier : python3 -m http.server 8000
Puis ouvrez http://localhost:8000

Les séances, validations et historiques sont stockés localement dans Safari.
